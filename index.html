2. UniFi Networking System

2.1 Ethernet Infrastructure

WAN、网关、交换、Wi‑Fi、NAS、Room Drop、线材与机柜的选型与适配。

2.1.1 ISP

Telus PureFibre 5 Gigabit：运营商光纤 → TELUS ONT (Optical Network Terminal)。ONT 只做光电转换。

  • 定稿：Nokia XS-010X-Q（优先；XGS-PON SFU：无 Wi‑Fi，1×100M/1/2.5/5/10G）或 Nokia XS-250X-A（次选；无 Wi‑Fi，常见 1×10G + 4×1G；Telus 实装更常见）。本宅只用 10G 口。优先机库存与技师意愿不保证。
  • 回退：Telus NAH（常见 NH20A / NH20T），开桥接，同样 10G 短跳进 UDM。
    • Router：默认。NAH 自做 NAT / DHCP / 防火墙；再挂 UDM = 双 NAT。
    • Port 10G Bridge：10G 口透传成 WAN，公网落到 UDM。
    • Port 1 Bridge：桥 1G 口，不够 5 Gig。
    • Full Bridge：所有口暴露给运营商侧；家用动态公网少，下游自扛防火墙。

2.1.2 Gateway

Dream Machine Pro Max：UniFi OS 一体机，承担路由、防火墙、VPN、威胁管理、统一控制面，并内建 Protect / Access / Network。WAN：ONT → 柜内 UniFi Premium Patch Cable → SFP+ WAN（插 SFP+ to RJ45 Adapter）。公网一般由 UDM DHCP 取得。不走面板 2.5G 铜 WAN；LAN SFP+ ↔ Pro XG 24 PoE SFP28，机柜内 10G Direct Attach Cable。八个 1GbE LAN，第一口接 UPS 2U Pro 管理口（见 §4.2），其余七口空闲。

2.1.3 Switching

有线核心：机柜一台 Pro XG 24 PoE 汇聚。Flex 2.5G 在 Media，Flex 2.5G PoE 在 Garage。边缘见 §2.1.6。上联用 10G RJ45（不用 combo 上的 SFP+），不接墙端 AC。

  • Pro XG 24 PoE：16×10G + 8×2.5G，另有 SFP28 上联接 Dream Machine Pro Max。负责 Wi‑Fi、门禁上行、HA / Wallpanel、CCTV（Protect Viewport）、各 Room Drop（Media / Garage 两路远端接边缘 Flex）、配电盘。机柜 NAS（Synology FS2500，见 §2.1.5）占 2×10G LACP。16 个 10G 口用 14，空 2。八个 2.5G 口全用。
  • Flex 2.5G（Media）：八个 2.5G 下联只传数据。Media 要多口有线。
  • Flex 2.5G PoE（Garage）：八个 2.5G 下联可供电。车库边缘有 Wi‑Fi、门禁、USL。

2.1.4 Wi‑Fi

  • 主屋：Basement / Main / Upper 三层墙面 U7 Pro Wall ×3（配 U7 Pro Wall Paintable Flush Mount），2.5G / Wi‑Fi 7。
  • 车库：U7 Lite。

2.1.5 NAS

机柜 FlashStation FS2500：1U，官方 DSM，进 Mechanical Room 机柜（见 §2.1.8）。四柱导轨 Synology Rail Kit RKS-01（深度 553–834 mm，另购）。口位见 §2.3。

  • 网络：内建 2×10GbE，机柜内经下配线架，UniFi Premium Patch Cable 做 LACP → Pro XG 24 PoE；另有 2×1GbE。Den 的 Mac Studio 经该室 10G Drop 进入同一交换机。
  • 存储：12×2.5″ SATA SSD，不插 HDD。录像、影音、文件、模型库分 Storage Pool / Volume。内存 16–32 GB（出厂 8 GB，上限 32 GB）。
  • 供电：单电源 350 W，100–240 V，接市电 / Powerwall 3。

2.1.6 Room Drops

七个房间（Media / Den / Master / BR1 / BR2 / Seating / Garage）各拉两根 UniFi Indoor Cable Cat6A CMR。Den 墙面两口都终结并启用。其余六间墙面只终结在用的一根；备用线在下配线架终结，不占交换机口。Den 两根全开。HA 进上配线架。其余 13 根 Room Drop 进下配线架。Media 与 Garage 的在用口在远端接边缘 Flex，机柜端从下配线架短跳进 Pro XG 24 PoE。

  • Den：墙面 Universal Paintable Keystone Wall Plate（H-2P 横向双口）。一口接 Mac Studio（机身 10GbE），配线架短跳进 Pro XG 24 PoE 的 10G 口；另一口接 ameriDroid PoE Mini PC for Home Assistant（见 §3.1），上配线架短跳进同一交换机的 10G 口。
  • 非 Den：墙面 Universal Paintable Keystone Wall Plate（V-1P 纵向单口）。Media / Garage 在用口经短跳接各自 Flex 的 10G RJ45 上联。
  • 面板采购：H-2P 一包、V-1P 两包。配线架两块 24-Port Blank Keystone Patch Panel。上配线架：Protect Viewport、U7 Pro Wall ×3、主屋 Door Hub Mini ×4、Den HA、Wallpanel ×3。下配线架：Synology FS2500 两口、Room Drop 回线 13 根、配电盘 1 根。车库 Door Hub Mini 在车库 Flex 2.5G PoE 上。空孔 20，Keystone Blank Insert 一包。Cat6A Keystone Jack ×50，采购 12-Pack ×5。配线架 28，墙面 8（Den 两只，其余六间各一只），设备端 14：U7 Pro Wall ×3、主屋 Door Hub Mini ×4、Synology FS2500 ×2、Protect Viewport、Wallpanel ×3、配电盘。永久链路两端都终结在模块上，配线架一侧短跳进交换机，设备一侧短跳进终端。

2.1.7 Cables

永久链路：UniFi Indoor Cable Cat6A CMR。短跳：UniFi Premium Patch Cable。采购数量见 §2.3。

  • 永久入墙 / home-run：UniFi Indoor Cable Cat6A CMR ×3（每盒 305 m）。Room Drop、主屋 Door Hub Mini、AP、Wallpanel、Protect Viewport。静压箱路径改用 UniFi Indoor Cable Cat6A CMP。
  • 柜内 / 墙口短跳：UniFi Premium Patch Cable。相邻、口位对齐的用 0.15 m ×22（上配线架到 Pro XG 24 PoE 12，下配线架到同一交换机 10，含配电盘）。隔一格用 0.3 m ×1（ONT / NAH 到 Dream Machine Pro Max）。备用 Room Drop 不跳。
  • 户外摄像头与读头：UniFi Premium Patch Cable Outdoor，黑色。十根从就地 Door Hub Mini 到门口设备，不进机柜。读头与前门 G6 Pro Entry 2 m ×5；Frontyard Turret 5 m、Courtyard Turret 5 m、Backyard Turret 8 m、Walkway Bullet 8 m、Laneway Turret 12 m。合计 48 m，按门口就地汇聚估算。五条摄像头线各在 Door Hub Mini 一端串一只 Ethernet Surge Protection。
  • 光 / DAC：Dream Machine Pro Max↔Pro XG 24 PoE 用 10G Direct Attach Cable，0.5 m ×1。不进配线架，不承载 PoE。
  • 非以太网：门锁 LOCK 为 Wet 12V 控制线；DPS 为干接点门磁（本宅 Securitron DPS）；Tesla 控制为 CAN。LOCK / DPS / Tesla CAN 不按以太网线规。

2.1.8 Server Rack

Mechanical Room 落地四柱开放架：StarTech 4POSTRACK15U（见 §2.3）。导轨深度 22″–40″ 可调，装时调到约 31–32″（≈800 mm），兼容 Pro XG 24 PoE 与 RKS-01（见 §2.1.5）。机柜 UPS 定为 UPS 2U Pro（见 §4.2），2U，置于架底。一块 Fixed Rack Shelf 放 ONT 或 NAH。NAH 平放，高 32 mm。XS-250X-A 外形未公布。两块 24-Port Blank Keystone Patch Panel 贴住 Pro XG 24 PoE，搁板在上配线架之上。网关与搁板之间、NAS 与 UPS 2U Pro 之间各留 1U，正面各装一块 1U Vented Panel。Dream Machine Pro Max 正上方一块 2U Vented Panel。顶部余下 3U 用一块 2U Blank Panel 和一块 1U Blank Panel 封上。

机柜正面，自上而下，每一行 1U（编号自架底起）。重的在下。此排布共 15U。端口按面板：实心在用，空心已终结未跳，灰框为 Keystone Blank Insert。配线架按下行设备的口速和 PoE 上色；未定 Room Drop 按 10G PoE+++。配电盘按 1G、不供电。Synology FS2500 网口在机尾。

      3. Home Assistant System

      本地智能家居控制面：Den Hub、墙面 Wallpanel（×3）+ Den 长期桌测一套，与 §3.3 Device List。射频硬件（ZBT-2×2 + ZWA-2）落在 §3.1；IP 侧（Wi‑Fi / MQTT / Matter-over-Wi‑Fi）不另买棒。录像 / 门禁仍归 §2.2 UniFi Protect / Access；HA 只做联动，不取代 NVR 或 Access 逻辑。买设备前先查 HA Integrations / 社区兼容表；优先本地控制，云只作后备。

      Bluetooth / BLE：日常说的「蓝牙」常混用两套：Bluetooth Classic（音响、旧串口等）与 Bluetooth Low Energy（BLE）（低功耗广播与短连接）。Home Assistant 的 Bluetooth 集成只支持 BLE，不支持 Classic。本宅短距传感（BTHome 温湿度等）、部分体脂秤与辅助存在探测走 BLE；墙体衰减大、无 mesh，不靠 Hub 机身蓝牙，而靠房间级 Bluetooth Proxy（remote adapter）。按需、非 Day‑1：每层 1–2 台以太网 / PoE ESP32（优先外置天线，如 Olimex ESP32-PoE-ISO-EA）刷 ESPHome Bluetooth Proxy，专做 BLE 广告与短连接；Proxy 板本身走有线，避免再打 Wi‑Fi 与 BLE 抢射频。不拿 ZWA-2 兼 BLE 主力。厂商私有桥（Lutron Caseta 等）与红外-only 设备的 IR blaster 有才买；重要安防不单靠手机蓝牙存在。

      Wi‑Fi：高带宽或厂商只给了 Wi‑Fi 的设备（部分电器、Matter-over-Wi‑Fi、少数 IoT）走本宅 UniFi AP；HA 不另建 Wi‑Fi，也不在 Hub 上插 USB Wi‑Fi 棒。吞吐高、配网熟，但占 AP airtime、云依赖机型断云即残，且 2.4 GHz 与 Zigbee / Thread 互害。本地 API 清晰的品牌可用；能有线（Room Drop）的固定设备走有线。补充通道，不是传感器主干。

      MQTT：软件消息总线，不是无线制式；跑在 Ethernet / Wi‑Fi / IP 上。本宅在 Hub 上按需装 Mosquitto，供 Tasmota / ESPHome、部分 DIY、以及日后若上 Zigbee2MQTT 时进 HA。解耦灵活、可全本地；要自管 Broker 与发现约定。ZHA 直连 Zigbee 时不必为 Zigbee 而装 MQTT；大量 ESP 或改 Z2M 时再升格为基础设施。

      Matter：应用层互联标准，可跑在 Thread 或 Wi‑Fi / Ethernet 上。HA 用 Matter Server 做本地控制器；Matter-over-Thread 经 §3.1 第二根 ZBT-2 Border Router，Matter-over-Wi‑Fi 经局域网、不占该棒。多生态本地控制的长期方向，不是把现有稳定 Zigbee / Z-Wave 网推倒重来的理由。Thread / Matter 对 IPv6 与 mDNS 敏感，防火墙未放行前不要先拆 VLAN。

          • 接线：原装 USB-C→USB-A 插一只 USB 2.0-A；天线见上方安装总则。

          • 接线：原装 USB-C→USB-A 插一只 USB 2.0-A；天线见上方安装总则。

          • 取舍：设备便宜、有电路由一开则电池末端跟网、ZHA 路径短；与 Wi‑Fi / Thread 同处 2.4 GHz 须规划信道，部分 Tuya 私有 cluster 在 ZHA 上残缺，mesh 质量取决于插电节点密度而非协调器标称距离。IKEA / Hue / Aqara（注意桥与直连）/ Sonoff 官方线更稳；白牌电池传感先用插座 / 灯铺路由骨架。天线勿塞封闭金属腔。
        • Home Assistant Connect ZBT-2（Thread）
          • 接线：原装 USB-C→USB-A 插一只 USB 2.0-A；天线见上方安装总则。
          • 角色：低功耗 IPv6 mesh 传输层，主要承载 Matter-over-Thread；本棒固定作 HA Border Router（不兼 Zigbee；不依赖 HomePod / Nest）。不另买第三根 Thread 棒（除非日后独立实验室网）。新买电池类 Matter 的传输首选；不取代现有 Zigbee 库存。
          • 取舍：为电池设备优化，经 BR 可 IP 直达；Thread 本身不是应用层——无 Matter / 厂商应用则「裸 Thread」无意义；前期设备贵、与 Zigbee 同频要分开天线与信道。掉线常见于 BR 断电、IPv6 / mDNS 被 VLAN 误伤、单 BR 位置极差。日后 Apple TV / Nest 可作辅 BR，本宅以 HA 棒为准。

      4.2 UPS 2U Pro

      两台并联 Powerwall 3 承担全屋持续供电。机柜 UPS 定为 UPS 2U Pro：2U，机身深 630 mm，置于架底（见 §2.1.8）。1920VA / 1920W，线路互动，电池端纯正弦；8 个 NEMA 5-20R 均带电池。输入 NEMA 5-20P，机柜回路用 20A，并纳入 whole-home backup。
